# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through
[GitHub security advisories](https://github.com/Russelcruz28/filament-page-builder/security/advisories/new)
with a description of the issue, the affected version and, if you can, steps to reproduce it.

You will get an acknowledgement within a few working days. Fixes ship as a patch release
on the latest minor version.

## Supported versions

Only the latest release receives security fixes.
